# Hi, I'm @jeff-spurlock

Senior software engineer at Hello Bello, Hyland's, and OneLasso. Mostly full-stack, mostly TypeScript, mostly e-commerce and SaaS.

## What I'm working on

**Hello Bello's headless storefront and CMS.** A Next.js storefront running against the Shopify Storefront API, with content managed through a MongoDB-backed CMS. Recent work there includes an FFmpeg pipeline that fires on CMS lifecycle hooks, compressing and downsampling video into device-specific variants before it lands in Cloudflare R2. Video payload is down 89% on desktop and 95% on mobile, with nothing extra for content editors to do.

**OneLasso's Partnership Operations Platform.** Rails and Next.js, with a GraphQL API I designed. Connects SaaS providers with their implementation partners through filterable directories, lead capture, and integration request workflows.

**A self-hosted email marketing platform.** A personal project, and the one I'm most curious about. Most campaign tools price out the organizations that need them most, so this one is built to run on stacked free tiers and stay genuinely affordable for small-budget groups. Open source, and still early.
